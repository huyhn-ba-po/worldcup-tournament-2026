ℹ️ Giới thiệu

WC2026 Predictor — webapp dự đoán FIFA World Cup 2026 kết hợp data thống kê + AI, minh bạch hoàn toàn.

🎯 Mục tiêu

Đem statistical rigor (Elo, Poisson, WCOI) kết hợp với LLM reasoning (Gemini) để dự đoán 104 trận WC2026. Mọi data, formula, backtest, weights đều công khai để bạn tự kiểm tra và đóng góp.

📦 Tech stack

  • Backend: Node.js + Fastify (multi-page webapp)
  • Frontend: Vanilla JS + Tailwind CSS (no build step)
  • AI: Google Gemini 2.5 Flash (constrained Bayesian updater)
  • Cache: LRU in-memory (24h TTL cho predictions)
  • Data: openfootball/* (CC0 Public Domain), 7m.com.cn (scrape)

🔗 Sources

  • 📂 GitHub: Yamus142/worldcup-tournament-2026
  • 📊 Data primary: openfootball/internationals (1872-2025, Mart Jürisoo mirror)
  • 🏆 WC data: openfootball/worldcup.json
  • ⚽ Live updates: 7m.com.cn/2026worldcup
  • 🏛 FIFA official: FIFA WC2026
