Giới thiệu

WC2026 Predictor — webapp dự đoán FIFA World Cup 2026 kết hợp data thống kê + AI.

Mục tiêu

Đem statistical rigor (Elo, Poisson, WCOI) kết hợp với LLM reasoning (Gemini) để dự đoán 104 trận WC2026. Mọi data, formula, backtest, weights đều công khai để bạn tự kiểm tra.

Tech stack

  • Backend: Node.js + Fastify (multi-page webapp)
  • Frontend: Vanilla JS + Tailwind CSS (no build step)
  • AI: Google Gemini 2.5 Flash (constrained Bayesian updater)
  • Cache: LRU in-memory (24h TTL cho predictions)
